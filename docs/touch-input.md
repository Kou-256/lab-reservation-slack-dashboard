## タッチ入力（PIN廃止後）

個人PINは廃止しました。登録済みの氏名を選んで予約・変更・キャンセルを行います。氏名の選択は本人確認ではなく、他の利用者の氏名でも操作できます。端末キー認証・所有者として選択した氏名の照合・重複検査・二重送信対策は維持します。古いPINハッシュは移行のためDBに残しますが、一切照合せず、変更・リセットAPIは廃止しました。

日時・時刻・台数・利用者はネイティブのプルダウンを使用します。用途は候補から選ぶか「自由入力」を選択し、文字欄をタップしてWindowsのタッチキーボードで入力します。WebページからOSキーボードを必ず開くことは保証できないため、タブレット側の設定が必要です。

- Windows 11：設定の「時刻と言語」→「入力」→「タッチキーボード」で表示条件を「常に」など運用に合わせて設定します。
- Windows 10：設定の「デバイス」→「入力」で、物理キーボード未接続時のタッチキーボード表示を有効にします。表示名はWindowsの版により異なります。
- 必要ならタスクバーにタッチキーボードのボタンを表示し、手動でも呼び出せるようにします。PIN入力や独自の日本語キーボードは不要です。

公式手順：https://support.microsoft.com/en-us/windows/hardware/input-devices/enable-and-disable-the-touch-keyboard-in-windows

## 明るさ

通常のMicrosoft Edge内のWebページには、Windowsの液晶バックライトの明るさを変更する対応APIがありません。非標準のmozBrightnessはEdge向けには使えません。Webの黒いオーバーレイは実際の輝度変更・節電にはならないため追加していません。Windowsのクイック設定・アクションセンターまたは「設定」→「システム」→「ディスプレイ」の明るさで変更してください。Webから実輝度を変更するには各端末への専用アプリ等の導入が別途必要です。

参考：https://developer.mozilla.org/en-US/docs/Web/API/Screen/mozBrightness
