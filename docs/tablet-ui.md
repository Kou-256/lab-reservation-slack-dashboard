# 予約端末のUI

設備別画面は青〜青緑の空き表示、赤の予約時間中表示、グレーの不明・停止表示を使い、文字と形でも状態を区別します。実際の装置の稼働状態は検知しません。

数量予約のスケジュールは設定済みの場所ごとに行を分け、時間帯別の予約台数を表示します。タップすると空き・点検・場所未設定の台数を確認できます。予約時刻は終了を含まない区間として扱い、日跨ぎ・重複予約にも対応します。

スターラーのSVGは場所別の予約台数を示す概念図です。赤い回転表示は予約中、青い静止表示は空き、グレーは停止・不明です。個体の割当や実稼働を示すものではありません。場所未設定の予約と点検台数は、空きを過大表示しないよう保守的に差し引きます。通信断で情報が古くなると回転を止めて不明表示に切り替えます。OSの「動きを減らす」設定にも対応します。

横向きタブレットの詳細画面は表示領域に合わせて配置し、下部の予約一覧を独立してスクロールできます。小さい縦長画面では通常のページスクロールを使います。

変更箇所は `dashboard/terminal.css`（配色・配置）、`dashboard/stirrer.ts`（SVG）、`shared/occupancy.ts`（台数集計）、`dashboard/app.ts`（画面への組み込み）です。ビルドスクリプトが追加のCSSとモジュールを配信します。既存の予約保存処理・DB構造の変更や新しい実行時依存パッケージの追加はありません。

## 可読性と操作

カードのカレンダーは高さと下端をそろえ、予約情報の有無で位置がずれないようにしています。画面名のボタンから一覧に戻れます。スターラーは左列の上から下、次の列の上から下の順に並べます。次の予約までの時間は「あと1日2時間30分」の形式で表示します。

[Astryxの文字階層](https://github.com/meta/astryx/blob/main/docs/design/typography-hierarchy.md)と[余白ガイド](https://github.com/meta/astryx/blob/main/packages/cli/assets/docs/tree/layout-spacing.doc.mjs)を参照し、既存TypeScript画面の見出し・本文・補助情報と操作部品の大きさを整理しています。

ヒラギノ角ゴシックは端末にインストールされたフォントを参照します。フォントファイルは公開版に含まれません。利用に必要な権利のある`hiragino.zip`を別途用意し、`scripts/install-tablet-font.ps1`と同じフォルダーに置いて、ダッシュボードを使うWindowsユーザーで次を実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-tablet-font.ps1
```

現在のユーザーにW3/W6を登録します。サインアウトして再サインインした後、Edgeを起動してください。未導入の端末では代替フォントを利用します。

## 4連装置・次の予約・履歴

スターラーは、銀色の2×2プレートと黒い共通ベース・液晶風操作盤を持つ4連装置として表示します。左上→左下→右上→右下の順に埋めます。回転マークは予約状態を表し、温度や回転数の実測値は表示しません。

詳細画面の左側には「次の予約」欄を置き、予約者と開始日時を表示します。「設備一覧」ボタンは廃止し、上部タイトルからTOPに戻ります。カレンダーは場所別の2行、予約操作ボタンは2列×2行にそろえています。

「過去の履歴」では終了した予約を終了日で検索できます。1回の検索範囲は366日以内、30件ずつページ送りできます。キャンセル・進行中・未来の予約は含みません。実際の装置使用を検知した記録ではありません。履歴APIにも既存の端末認証を適用し、データは保存・変更しません。

## 全体スケジュールと数値選択

「全体スケジュール」から、全設備の予約を共通の時間軸で比較できます。日付、0〜24時／8〜20時の表示、設備検索に対応し、重なる予約は別レーンに分けます。バーを押すと予約者・用途・日時・台数・場所を確認し、その設備の詳細画面へ移動できます。予約一覧からも同じ情報を確認できます。

空き状態では中央に次の予約を表示し、同じ予約を左側には重複表示しません。予約時間中だけ左側に次の予約を表示します。

予約の年・月・日・時・分、使用台数はプルダウンで選択できます。月の日数と閏年に合わせて日を調整します。バックエンドと予約保存先の追加・変更はありません。
